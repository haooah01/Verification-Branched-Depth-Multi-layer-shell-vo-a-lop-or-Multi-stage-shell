# Verification: Branched Depth — Multi-layer Shell & Multi-stage Core

Tài liệu chuẩn hóa thuật ngữ kỹ thuật chuyên ngành (cơ khí, cáp điện, vật liệu và cấu trúc phân cấp) nhằm thống nhất định nghĩa giữa thiết kế và triển khai.

---

## 1. Bảng đối chiếu thuật ngữ chuẩn (Terminology Mapping)

| Thuật ngữ tiếng Việt | Thuật ngữ tiếng Anh | Lĩnh vực áp dụng & Ngữ cảnh sử dụng |
| :--- | :--- | :--- |
| **Vỏ** | `Shell` | Cơ khí, kết cấu (vỏ bọc cứng, vỏ chịu lực, lớp bao ngoài). |
| **Vỏ bọc (cáp)** | `Jacket` / `Sheath` | Cáp điện, viễn thông (lớp vỏ bảo vệ cách điện/chống nhiễu). |
| **Ruột / Lõi** | `Core` | Lõi trung tâm, ruột dẫn hoặc thành phần chịu tải bên trong. |
| **Nhiều cấp vỏ** | `Multi-layer shell` | Kết cấu vỏ gồm nhiều lớp vật liệu xếp chồng đồng tâm. |
| **Vỏ đa cấp / nhiều tầng** | `Multi-stage shell` | Kết cấu vỏ phân chia theo từng tầng hoặc giai đoạn hoạt động. |
| **Nhiều cấp ruột / Đa lõi** | `Multi-core` | Cấu trúc chứa nhiều lõi/ruột độc lập nằm chung trong một lớp vỏ. |
| **Lõi đa cấp** | `Multi-stage core` | Cấu trúc lõi phân tầng theo cấp độ xử lý hoặc chịu lực. |

---

## 2. Phân biệt sắc thái kỹ thuật

* **`Multi-layer` vs. `Multi-stage`:**
  * Dùng **`Multi-layer`** khi nhấn mạnh vào **cấu trúc vật lý xếp lớp** (ví dụ: vỏ bọc 3 lớp chống ăn mòn, cách nhiệt).
  * Dùng **`Multi-stage`** khi nhấn mạnh vào **trình tự phân cấp hoặc giai đoạn vận hành** (ví dụ: hệ thống bảo vệ đa tầng, phân cấp độ sâu nhánh).
* **`Shell` vs. `Jacket` / `Sheath`:**
  * Dùng **`Shell`** cho các chi tiết cơ khí, bồn bể, kết cấu cứng hoặc mô hình trừu tượng (như *Shell-Core architecture*).
  * Dùng **`Jacket` / `Sheath`** chuyên biệt cho ngành dây cáp điện và cáp quang.
